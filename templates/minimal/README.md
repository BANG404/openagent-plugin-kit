# minimal template

The smallest useful package: a manifest and one Skill.

```text
plugin.json
skills/hello/SKILL.md
```

Edit `plugin.json` first, then replace `skills/hello/`. Remember that the Skill
directory name and the frontmatter `name` must match exactly.

Install the directory in OpenAgent through **Settings -> Plugins -> Install** to
confirm the Skill appears in the catalog.
